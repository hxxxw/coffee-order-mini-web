# 野火咖啡 · 点单 H5 Demo

给客户演示微信小程序点单流程用的静态 Demo。**无需后端、无需安装、双击即可运行。**

## 怎么打开

双击 `index.html`，用 Chrome / Edge / Safari 打开即可。

建议按 `F12` 打开开发者工具，切到手机模式（iPhone / 390×844）查看效果；页面为纯移动端 H5，全屏铺满展示。

> 首次打开如果浏览器做了安全拦截，属正常现象。Demo 全部为本地文件，无任何网络请求。

## 建议的演示路线

1. **首页** — 品牌字标 + 照片轮播 Banner（自动切换）、门店到店自取入口、招牌商品、活动条
2. **点单页** — 左侧分类与右侧商品**双向联动**：点左侧平滑滚动，滚右侧左侧高亮自动跟随
3. **点商品** — 底部弹出规格层，选杯型 / 温度 / 加料 / 数量，合计实时计算
4. **加入购物车** — 注意 Tab 栏「点单」角标、底部购物车条、商品卡上的数量角标会同步更新
5. **购物车弹层** — 可增减数量、删除单品；同规格自动合并，不同规格分行显示
6. **去结算 → 提交订单** — 满30 减 6、满 60 减 12，提交后模拟支付（约 1.2 秒）
7. **订单页** — 取餐号、商品明细、规格数量、支付状态、实付金额、订单进度
8. **我的** — 用户信息、我的订单、优惠券、账户余额、联系我们

## 技术说明

- 纯静态：HTML + CSS + 原生JS，**无框架、无构建、无外部依赖**
- 商品图为内联 SVG 生成，断网也能完整演示
- 首页轮播使用本地照片（`assets/img/banner-*.png`），无外部请求
- 全站共用一份数据（`assets/js/store.js`），购物车状态跨页面保持一致
- 已适配移动端屏幕；纯 H5 全屏铺满，无手机壳边框

## 目录结构

```
index.html                页面入口
assets/css/base.css       基础样式、设备外壳、页面切换
assets/css/components.css 组件样式：Banner、商品卡、弹层、购物车
assets/css/pages.css      结算页、订单页、我的页
assets/js/data.js         模拟数据（商品、分类、规格选项）
assets/js/icons.js        图标库
assets/js/store.js        全局状态：购物车、订单、金额计算
assets/js/app.js          页面渲染、路由、事件绑定
preview/                  各页面截图（仅参考，删掉不影响运行）
verify.cjs                自动化验证脚本（可选，运行需 Node 环境）
```

## 常见问题

**Q：想改商品价格 / 名称 / 图片？**
改 `assets/js/data.js` 即可，商品、分类、Banner、规格选项都在这里。

**Q：想加商品？**
往 `PRODUCTS` 数组里加一条，`cat` 填已有分类 id（coffee / latte / tea / bakery / meal）。图片会自动按顺序生成，无需单独准备。

**Q：支付是真实的吗？**
不是。点击提交后只是模拟 1.2 秒 loading，然后直接显示支付成功，方便演示完整流程。

**Q：数据会保存吗？**
不会，刷新页面即恢复初始状态，方便反复演示。
